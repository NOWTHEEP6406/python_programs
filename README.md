# Python Programs

A collection of Python programs created for learning, practice, and problem-solving. This repository contains simple and beginner-friendly Python programs covering different programming concepts.

## 📌 About

This repository contains Python programs demonstrating concepts such as:

* Variables and data types
* Input and output
* Conditional statements
* Loops
* Functions
* Lists, tuples, sets, and dictionaries
* String manipulation
* File handling
* Exception handling
* Object-oriented programming
* Basic problem-solving and algorithms

## 🛠️ Requirements

* Python 3.x
* Any code editor or IDE such as:

  * Visual Studio Code
  * PyCharm
  * IDLE
  * Jupyter Notebook

## 🚀 How to Run

1. Install Python 3 from the official Python website.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Run a Python program using:

```bash
python filename.py
```

On some systems, you may need to use:

```bash
python3 filename.py
```

```python

```

```text

Hello, Alex
```
